# Placebo matching

Generated by `python -m futuresres.levels.match_report`. LEVEL_HYPOTHESES.md, methodological core.

**Every L-series result reports (real - placebo), not (real - 0).** Price reacts at arbitrary levels, so a raw reaction statistic is not evidence that a level matters. This document is the evidence that the placebo comparison is valid at all.

Offsets are SHA-256 of (session date, level type, index within session), mapped to +/-[0.3, 1.5] x ATR(20). Deterministic across processes - never Python's salted `hash()`, which is the bug that forced a floor sweep to be discarded and re-run earlier in this project.
